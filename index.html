The Hungarian method works on this table. It picks one cell per row and column so the picked cells add up to the smallest possible sum. Ringed cells are the pairs in the selected method. Hover a cell to see the pair on the map.

How it works

Every vehicle-request pair has a cost: the straight-line distance. The Hungarian method finds the one-to-one pairing with the smallest total cost, and it does so in polynomial time instead of trying every combination.

Two simpler rules are shown for comparison. Closest pair first repeatedly takes the nearest free pair. Request order serves requests in the order they were added, each taking the nearest free vehicle. Both can be noticeably worse. Try the "Closest-first trap" scene.

Limits. It minimises the total, so one pickup can still be long. The pairing is made once for the points as they are now: no time, traffic, moving vehicles or later requests. Distance is straight-line on a made-up 100 x 100 plane, not a real map.

The matching code is in src/core.js and is checked against brute force in tests/core.test.js. All points are generated or placed by you.
